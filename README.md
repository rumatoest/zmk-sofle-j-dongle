# Better config for Sofle-J ZMK Dongle from PandaKB

I do respect the quality of a hardware builds from [Panda KB](https://pandakb.com)
but I have to say that their keyboard layout sucks.

This is an attempt to make a layout that will not mess with your muscle memory to much.
I hope it will make switching between split/regular keyboards much easier.

## Understanding layout

Most keys are located on the similar positions as on a regular keyboard.
But it is not always usefull thus I duplicates some of them on additional layers.

I'm still working on this layout. It has many empty spots for the left hand. This is where you can customize it.

### Base layer

Right half is missing at least 1 keys colum.
Thus puting all keys at their regular places is not possible.

So Enter & Backspace were moved to different places but you can still press backspace wit an index finger.

Esc placed on an extremely rare used CapsLock place so it would not harm your typing.

It also possible to replace Alt and Ctrl keys with some others but IMHO it is better to use modifiers with both hands.

### Layer 1

This one contains missing keys from a base layer and arrow keys.

Enter & Esc are located in familiar places with CapsLock as well.

Thought that it is more convinient to use "_","+","{","}" without Shift so there are separate keys for a left hand.

Delete is present on this layer with an another Backspace.

### Layer 2

This is mostly for your Fn buttons and a NumPad.
Num pad layout is not exacly the same but it is better than having a separate layer for it.

Esc, Enter & CapsLock are still on familiar places.

### Mouse layer

Controlling mouse from keyboard is kinda cool.
You can get use to it and may not touch your mouse most of the time.

### Configuration layer

This is and odd type of layer with only keyboard specific configs and symmetric buttons for a system actions: soft off, reset, bootloader.

Cfg layer is togglable from both halves.
**And there is a reason for that** in a case if half of keyboard lost connection or lagging you can toggle it to cfg layer and reset.
